# Tarea de Complejidades Algoritmicas

## Instrucciones

Como parte de nuestro estudio sobre complejidades algoritmicas, se te solicita que implementes un algoritmo para cada una de las siguientes clases de complejidad. Debes incluir estos algoritmos en un archivo llamado `nombre-cedula.js`. Asegúrate de utilizar los algoritmos que hemos visto en clase y de comentar adecuadamente tu código para indicar qué algoritmo estás implementando y por qué corresponde a la complejidad indicada.

### Complejidades a Implementar

1. **O(1) - Complejidad Constante:**
   - Implementa un algoritmo que siempre ejecute una cantidad fija de pasos, sin importar el tamaño de la entrada.   

2. **O(Log N) - Complejidad Logarítmica:**
   - Implementa un algoritmo que divide repetidamente la cantidad de datos en cada paso.   

3. **O(N) - Complejidad Lineal:**
   - Implementa un algoritmo que recorra cada elemento de la entrada una sola vez.   

4. **O(N Log N) - Complejidad Log-Lineal:**
   - Implementa un algoritmo que combine un proceso lineal con uno logarítmico.   

5. **O(N^2) - Complejidad Cuadrática:**
   - Implementa un algoritmo donde el tiempo de ejecución es proporcional al cuadrado del tamaño de la entrada.

6. **O(2^N) - Complejidad Exponencial:**
   - Implementa un algoritmo que crezca exponencialmente con el tamaño de la entrada.   

7. **O(N!) - Complejidad Factorial:**
   - Implementa un algoritmo cuyo número de pasos crece factorialmente con el tamaño de la entrada.
   
### Entrega

Sube tu archivo `nombre-cedula.js` al repositorio de github, en el folder Lab 5 antes de la fecha límite establecida. Asegúrate de probar cada uno de tus algoritmos con diferentes tamaños de entrada para verificar su correcto funcionamiento y la complejidad esperada.

### Evaluación

Cada algoritmo correctamente implementado y documentado recibirá una puntuación, y se valorará especialmente la claridad del código y la exactitud en la implementación de la complejidad correspondiente.
